Features

Everything you expect from a great Jellyfin client

And a few things you don't get anywhere else.

🎬 Playback

  • Direct play, transcode, and offline playback
  • Watch Together — synchronised group playback with in-session chat
  • Subtitle timing offset, fine-tuned live
  • Media-segment skipping (intro / credits)
  • Trickplay timeline scrubbing
  • Next-up overview when watching a queue

📚 Library

  • Browse, refresh content, and edit metadata
  • Download items and sync watch progress across devices
  • Server management with multi-user / multi-server switching
  • Jellyseerr / Seerr integration
  • Comic book reading support (.cbz, .cbr)

🖥️ Interface

  • Adaptive layout for phone, tablet, TV, and desktop
  • Dark / light mode with multiple color styles
  • Keyboard shortcuts
  • Chromecast + DLNA casting

🐳 Docker

Self-host Driftfin behind your own reverse proxy.

ghcr.io/hamadtheironside/driftfin:latest ghcr.io/hamadtheironside/driftfin-rootless:latest

The hosted web app only allows https connections to your Jellyfin server — a GitHub Pages limitation. Self-hosted web builds work fine over plain http.
